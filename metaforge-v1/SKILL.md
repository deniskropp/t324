# metaforge-v1 — The Forge of Forges

**Unified MetaForge v1.0** is now available as a loadable skill.

## Activation
When this skill loads, the Orchestrator automatically executes:
```
⫻cmd/lang:KickLang
⫻cmd/mode:MetaIterative
⫻cmd/exec:Orchestrator sync + KickGuard init
⫻data/state: metaforge_active
```

## Core Capabilities
- **Domain-agnostic spawning** of story, workflow, research, humor, code, life, or custom forges
- **Three-Agent-Core**: KickForge (TAS/Validation), KickFlow (Structuring/Coordination), KickGuard (Ethics/Integrity/Visuals)
- **6-Phase Protocol** with strict max 3 meta-iterations
- **KickLang DSL** native command layer
- **Persistent Meta-DNA** learning across sessions
- **Hybrid Consistency-Engagement Scoring** (target ≥ 8.5 for full assembly)
- **Consent-first** gates and banned-structure enforcement

## How to Use
Simply say any of the following:
- "spawn a forge for [domain]"
- "use metaforge for [archetype + domain]"
- "create a [story/workflow/research] using the forge of forges"
- Paste KickLang DSL or reference the MetaForge protocol

The skill will handle the full 6-phase process and present ready-to-use results.
