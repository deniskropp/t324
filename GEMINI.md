# Project: Unified MetaForge and OCS Documentation Repository

This repository serves as the central documentation, configuration, and instructional hub for the Unified MetaForge v1.0 and Orion Collective System (OCS) frameworks. It manages the meta-infrastructure for orchestrating workflows, creative forges (narrative, research, code), and multi-agent interactions using Task-Agnostic Steps (TAS) and the KickLang DSL.

## Key Concepts
- **Unified MetaForge v1.0:** A framework for spawning, iterating, and governing diverse domain-specific forges.
- **Three-Agent-Core:** A mandatory delegation model (KickForge, KickFlow, KickGuard) for task execution, workflow coordination, and ethical governance.
- **KickLang:** A Domain-Specific Language (DSL) used for orchestrating agents, defining states, and executing TAS protocols.
- **TAS (Task-Agnostic Steps):** The fundamental unit of execution and decomposition within this meta-framework.

## Repository Structure
- `docs/`: Technical playbooks, orchestration patterns, and architectural specifications (BPMN, MetaForge v1.0, Three-Agent-Core roles).
- `examples/`: Practical demonstrations of automated audits, forge outputs, and TAS templates.
- `metaforge-v1/`: Skills definition for the MetaForge system.
- `metatale/`: Configuration and TAS protocols for narrative-driven MetaTale orchestrations.
- `references/`: Supporting documentation for industry standards and the overarching Unified MetaForge protocol.

## Usage
When interacting with this project, recognize that you are operating within a structured, consent-based, meta-iterative environment. Follow the "Unified MetaForge v1.0 Playbook" (located in `docs/`) and adhere to the strict Six-Phase Execution Protocol for any forge-related tasks. Utilize KickLang syntax and ensure the Three-Agent-Core is properly invoked for all delegated work.
